# v1.14 — 正文重采样与跨平台可读性

## 本次真正改变的环节

原来是 `DOM → 浏览器 SourceGraphic → 单次曲面位移 → 屏幕`。

本版是 `DOM → 同一份 SourceGraphic → 1 / 2 / 4 个亚像素曲面采样分支 → 归一化合成 → 屏幕`。字体不依赖 macOS 专用平滑设置，也没有加入页面截图、本地产品图片读回、离屏文字复制或服务器依赖。

多点模式的每个 `feDisplacementMap` 都直接读取 **SourceGraphic**，并通过 `feComposite` 合成。不是只把一张位移图做得更细。四点分支分别读取输出像素中心周围 ±0.25 个物理像素的位置，对应 `P(x+offsetX,y+offsetY)`。两点模式取对称对角位置。合成权重之和为 1，防止单纯叠加导致颜色或透明度改变。不对正文施加高斯模糊。

位移场仍需表达这些不同的亚像素落点，因此改为按实际长宽与 DPR 分配网格、按纹理中心编码、缩紧位移编码范围。它是配合真实重采样分支的控制数据，不再被当作正文分辨率的替代品。

## 额外栅格化的清理

- 去掉卡片画面大字的 `drop-shadow` 滤镜。
- 将大字的 3D 透视旋转改为保留倾斜外观的 2D 旋转，悬停位移保留。
- 移除正文的 `-webkit-font-smoothing:antialiased`，使用浏览器与操作系统原生字体平滑；加入系统无衬线字体回退。
- 保留 CD 滑出、图片动画、卡片布局弹跳、横向惯性及全局曲面几何。没有为了清晰度给整页加 CSS 缩放。

## 设备策略

按屏幕像素密度、视口像素总数、可用的内存与逻辑核心提示选择档位，不识别或排除任何操作系统。缺少硬件提示时采用保守默认值。

| 条件 | 初始模式 |
| --- | --- |
| 视口不超过 180 万物理像素、至少 8 个逻辑核心、内存提示大于 4GB | 四点重采样 |
| 视口不超过 300 万物理像素、内存提示大于 4GB，且未满足四点条件 | 两点重采样 |
| 更高像素负担或内存提示不超过 4GB | 单点曲面；优先保持滚动性能 |
| 不支持合成算子 | 单点曲面 |
| 不支持曲面滤镜、开启强制颜色或生成位移场失败 | 真实 DOM 无畸变显示，取消点击坐标重映射 |

高像素密度设备本身已有较密的输出网格，仍可能有曲面采样损失；单点模式不代表这些设备已无锯齿。

每张数学位移图不超过 131072 个纹素。滤镜区域保持视口尺寸，不对整张长网页建立位图。正常滚动只移动真实内容，不重建控制图。跨显示器、页面缩放或窗口尺寸改变时重新计算。SVG 图片同时设置 `href` 与 `xlink:href`。

共享动画时钟观察连续帧间隔：一个 24 帧窗口里至少 12 帧超过 28ms 时，将多点档位减半；最低保留单点曲面。同一页面会话只降档，不反复切换清晰度；空闲长间隔与后台状态不触发降档。此处是性能保护机制，不能当作已经测得某一设备达到特定帧率。

## 兼容性与保留功能

目标是现代 Windows / macOS / Linux 桌面浏览器及 Android / iOS 浏览器，依据标准 SVG/CSS 能力选择增强或降级路径。直接双击 HTML 与静态 GitHub 托管使用同一份相对路径资源。保留真实文字、键盘焦点、表单、复制与预览交互，不以一张图片替代页面内容。

Cards / Grid 视图和五列布局保留。缺少 Web Animations 时直接切换布局；缺少容器查询字体单位时有普通字号回退。强制颜色模式同时隐藏暗角覆盖层。

## Showcase GPU 曲面层

卡片展示区新增解析曲面着色器：GPU 对每个屏幕像素直接计算反向采样坐标，不使用离散位移控制网格。卡片图像与文字在设备感知的高分辨率 Canvas 场景中绘制，再由 WebGL2 着色器做曲面映射；CSS 像素尺寸与输出分辨率分开管理，窗口连续缩放会合并到动画帧处理。原 DOM 卡片仍负责点击、键盘焦点、文字语义和屏幕阅读器内容。该层仅覆盖 Showcase；其余页面目前仍走原有 SVG DOM 滤镜和原生回退。

这消除了 Showcase 的 8 位位移图与稀疏网格误差，但当前文字由浏览器 Canvas 字体栅格器以高分辨率重绘，并非 MSDF 字形轮廓。对于固定英文标题，这为后续 MSDF 提供了直接接入点；任意中文字形要实现同级覆盖率，还需完整的字库图集生成和授权处理。没有真实跨浏览器画面对照，不能据脚本实现声称所有设备绝对零锯齿。WebGL2 不可用或强制颜色模式启用时保留原生卡片显示。

## 验证与局限

`npm run check`：22 项通过。新增检查包括直接运行的滤镜图中四路均读取 SourceGraphic、合成权重归一化、DPR 与内存分档、显示器密度变化时仅重建一次、慢帧时降档且不反复重建、强制颜色与不支持滤镜时仍保持可滚动的真实内容。原滚动与视图切换回归检查继续通过。

测试运行于脚本 DOM 环境，不是 Chrome / Firefox / Safari 的真实画面或设备实测，不能据此声称所有平台锯齿都已消除或帧率已提高。

SourceGraphic 的实际栅格尺寸仍由浏览器管理。本次实现的是对现有正文图像的多点重建，不是可控的 2×/4× 字形超采样；不能凭空恢复输入中已丢失的笔画细节。实际收益、轻微软化与性能成本需要真实浏览器画面对照确认。如果要求原生文字级别的清晰度且所有文字都经过明显非线性畸变，仍需要能显式控制内容渲染目标的另一套渲染架构及完整跨浏览器验证。

技术依据：[MDN feDisplacementMap](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feDisplacementMap)、[MDN k2 算术合成](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/k2)、[W3C SourceGraphic](https://drafts.csswg.org/filter-effects-1/#attr-valuedef-in-sourcegraphic)。
