# v1.3.0：横向作品卡片与导航/暗角调整

本版包含用户连续两次反馈的完整修改。

## 作品卡片

- 移除图片中 All ideas / Beauty / Lifestyle / Tech 分类条及其筛选逻辑，保留三张作品卡片。
- 参考指定的 6.93 秒录屏：黑底、16:9 圆角封面、大号白粉渐变标题、下方白色标题与灰色说明；悬停时封面略缩、出现粉色渐变描边、标题变粉。
- 新样式位于 `dist/showcase.css`。封面仍用本项目已有产品插画和文案，不把参考录屏中的 Nano Banana 当作新的活动作品。
- 卡片整块可点击，继续打开原有概念分镜；没有新增或伪称已有真实广告成片。
- 所有宽度下均为 `flex-wrap:nowrap` 的一行滚动，桌面显示约两张完整卡片及下一张局部；手机显示一张与下一张局部。
- 支持原生水平滚动、触摸滑动、鼠标拖动、左右按钮、方向键/Home/End；拖动后抑制误触点击。到达边界时禁用对应按钮。
- 键盘聚焦提供与悬停相同的描边/缩放/标题高亮反馈。

## 导航与暗角

- `.header` 不再放入 `.crt-surface`，导航保持原生 DOM 显示，不受几何畸变和 RGB 分离影响。
- 导航层级高于玻璃覆盖层，背景改为不透明白色，确保 Logo 与按钮不被暗角或颗粒影响。
- 镜头的视口对齐扣除内容容器的文档顶部位置，避免移出导航后曲面中心偏移。
- 固定暗角强度从 `.28` 降为 `.22`，渐变主要收紧到左右外沿约 4%、上下约 6% 和四角。中央透明区扩大；滚动仍不改变暗度。
- v1.2 的技术分析保留为历史记录；其中“导航包含在滤镜中”和旧暗角值已由本版取代。

## 实测

- 1440px 桌面：分类条 DOM 数量为 0；三张卡片顶坐标相同；滚动容器约 1361px、内容约 1798px；页面级 scrollWidth 与 clientWidth 均为 1425px。
- 左右按钮可前进和返回，末尾按钮禁用。
- 在封面上实际鼠标拖动后水平位置改变，没有误打开 dialog；普通点击仍可打开和关闭概念预览。
- 键盘焦点状态：描边 opacity=1、封面 scale=.968、标题颜色为粉色。
- 390px 手机：三张卡片顶坐标相同，容器约 343px、内容约 925px；页面级 scrollWidth 与 clientWidth 均为 375px。Next / End 可抵达末项并禁用 Next。
- 320px 窄屏另行检查页面溢出与单行排列。
- 导航不在滤镜容器中；计算背景为纯白，层级 60 高于玻璃层 45；暗角为固定 `.22`。
- 实机触摸手势和不同浏览器的悬停表现未做完整硬件矩阵测试；手机尺寸为浏览器视口模拟。
