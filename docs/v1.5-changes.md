## 裁切原因与修正

原轮播使用 38% 固定卡宽加 overflow-x:auto，容器不足以容纳第三张，因此产生容器内部的竖直截断。现在用完整卡片窗口：宽屏显示两张，700px 及以下显示一张。滚轮、左右按钮、方向键和拖动按一张推进，隐藏窗口外卡片，采用 14px 位移与淡入过渡。容器不裁切 CD 或圆角，无滚动条。纵向触摸保留页面滚动，横向手势切换整卡。
