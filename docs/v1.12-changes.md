# v1.12.0：位移采样精度优化

## 范围与限制

本版优化当前实时 SVG 路径中可以控制的位移采样精度，保留直接双击 HTML 的兼容性、曲率 `0.16`、导航隔离、卡片惯性和减速停靠。不重新引入页面截图、图片像素读回或 WebGL 初始化。

SVG 滤镜的正文中间缓冲由浏览器实现决定，当前代码不能可靠指定其尺寸或强制使用某一种抗锯齿算法。`filterRes` 已从当前[滤镜规范](https://drafts.csswg.org/filter-effects/#FilterElement)移除；规范也没有统一规定所有位移重采样的插值算法。因此不能把增加位移图尺寸、设置一个属性或添加字体平滑声明称为“已实现 2 倍正文超采样”。

## 已实施的改进

1. **位移图按屏幕比例与 DPR 生成。** 旧版固定 96×96；新版依据六个设备像素左右的目标间距分配采样点，有效 DPR 范围为 1～2，单边最多 512、总量最多 131072 个点。1920×1080 / DPR 1 使用 320×180，2560×1440 / DPR 2 使用 482×271。这里提高的是位移控制场的分辨率，并非正文截图分辨率。
2. **对齐纹理像素中心。** 旧版把第一个/最后一个纹理像素当成视口边界；图片放大采样时像素代表的是像素中心，因此存在半个控制单元的坐标偏差。新版在 `(x+0.5)/width`、`(y+0.5)/height` 处计算镜头关系，消除这个偏差。
3. **缩小 8 位编码的量化间隔。** 根据镜头公式解析求出每轴最大位移，再加小幅安全余量，不再用 `max(viewport)×0.06` 的宽松范围编码。1920×1080 的原始位移编码间隔从约 0.452px 缩小到 0.305px，曲面几何关系不变。
4. **请求高质量图像插值。** 在滤镜、位移图和位移原语上设置 SVG `image-rendering="optimizeQuality"`。这表达采样质量偏好，实际是否使用双线性、双三次等方式仍取决于浏览器，不能声称已强制选中双三次。
5. **只平滑位移场。** 场平滑幅度根据有效 DPR 调整，输入始终为 `field-raw`；正文 `SourceGraphic` 未添加高斯模糊、色差或锐化。
6. **让浏览器选择字体平滑方式。** 主体不再继承强制灰度字体平滑的设置。这不保证浏览器会恢复子像素抗锯齿；滤镜本身仍可能使用灰度抗锯齿。原有平移与合成路径保持不变，避免引入未经帧率验证的合成方式切换。
7. **处理像素密度变化。** 通过 resolution media query 监听显示器密度改变，即使 CSS 视口大小相同，也能重新生成正确密度的场。平常滚动只更新平移，不重建位移图。

## 数值对照

使用实际编码后的位移图，通过像素中心对齐的双线性重建，在 128×72 个探针位置与原始镜头公式比较。单位为 CSS 像素；表格为二维坐标误差的 RMS。

| 视口 / 实际 DPR | 原采样 RMS | 新采样 RMS |
| --- | ---: | ---: |
| 1440×900 / 1 | 0.257 | 0.063 |
| 1920×1080 / 1 | 0.333 | 0.090 |
| 2560×1440 / 2 | 0.444 | 0.114 |
| 390×844 / 3（场 DPR 上限 2） | 0.143 | 0.040 |

完整数据在 `lens-sampling-v1.12.json`，对照计算位于 `tests/lens-metrics.mjs`。

这些结果只证明**位移控制场的数值重建更接近解析镜头**。它们不包含浏览器实际插值、场模糊及文字栅格化，不代表字边锯齿减少了同样比例，也不是最终画面或帧率实测。

## 验证

- `npm run check`：语法检查与 16 项测试通过。
- 保留原有文件协议初始化、视口边界、导航隔离、滚动期间不重建位移图、HTTP 相对路径、惯性与减速停靠回归检查。
- 新增适配尺寸和内存上限、编码范围、重建误差、显示器密度变化及只模糊位移场的检查。
- 本地浏览器预览仍受工具安全策略限制，尚无本版浏览器字形对比截图、设备矩阵或 FPS 数据。

若之后仍需接近原生文字的清晰度，需要可控的高分辨率内容渲染、明确的重采样与最终降采样链路，并通过实际浏览器对照评估收益和帧率成本。当前版本没有把这条更大范围的渲染器改造混入稳定的本地文件路径。
