# v1.1.0 视觉调整

本版按用户反馈调整字号、字标和内容宽度。`v1.0.0` 标签保留，可比较两版。

- 页面 UI 全部使用无衬线字体：移除 Georgia 斜体标题以及等宽标签字体，标题、卡片、概念预览和弹窗统一为 DreamSans / Helvetica / sans-serif 回退。
- 小字号整体放大约 18%；桌面 body 为 17px，首屏正文 20px，区块介绍 16px，活动规则正文 14px。手机主要介绍 15–16px，规则与 FAQ 正文 14px。
- 从参考站公开 PNG 中的黑色字标轮廓描摹生成 `dist/assets/openart-logo.svg`，包含标志与 OpenArt 文字的真实 SVG path，无内嵌位图。导航和页脚共同引用此文件；页脚用 CSS 反色。Dream Ads 活动标签保留，360px 以下导航隐藏活动标签以给菜单留空间。
- 首屏最大宽度 1536px，后续内容区最大宽度从 1320px 提高到 1440px；桌面内容区左右边距从 48px 改为 32px。1440px 视口实测：首屏约 1424.7px，后续内容约 1360.7px（含浏览器滚动条差异），内容仍窄于首屏。
- 桌面导航折叠阈值提高到 1050px，并同步 JS 的菜单收起判断，避免大字号挤压导航。

检查：JavaScript 语法通过；1440px 桌面和 390px 手机实际截图；320px 下 documentElement.clientWidth 与 scrollWidth 均为 305px，无横向溢出；手机菜单展开/收起正常。Logo 两处加载成功；无衬线标题的计算字体已核实。除字号和导航阈值外，原有交互逻辑未变。
