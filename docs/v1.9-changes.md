# v1.9.0 Showcase scroll and CRT lens

## Changes

- Expanded the showcase from three to six concepts, retaining the existing three visual themes and product illustrations while adding distinct storyboards and copy.
- Captures wheel input over the entire showcase, including its heading and controls. Vertical wheel input advances the horizontal rail while it can move; outward input at either rail boundary returns control to page scrolling. Horizontal wheel input at a boundary is translated to vertical page scrolling. Both axes keep using the shared Lenis animation clock.
- Increased the CRT radial refraction coefficient from `0.16` to `0.24` and corrected its radius for viewport aspect ratio. Added subtle, fixed-position chromatic edge separation and fine grain. The header remains outside the composited surface and the vignette stays static.
- Sized shader uniform arrays and hover state from the actual card count; disc textures cycle through the three product types so added cards retain the right artwork.

## Verification

- `npm run check` passes for the application, CRT compositor, and scroll diagnostics scripts.
- `git diff --check` passes.
- Browser rendering and wheel handoff could not be visually exercised in this environment because local preview access is blocked by the browser security policy. The new curvature and edge handoff are code-verified but still need a local visual check.
- User-provided recording frames are kept as local, untracked reference files and are excluded from the release commit.
