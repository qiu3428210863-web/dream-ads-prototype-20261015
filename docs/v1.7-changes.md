# v1.7.0 滚动手感与性能排查

## 参考站实际实现

2026-10-17 读取 https://www.shader.se/#about-us 的公开前端脚本，定位到：

`https://www.shader.se/_next/static/chunks/04kr7kd5riobb.js?dpl=dpl_AadA2KVJaJtKN5QXgQu1gAVrbmig`

该构建包含 Lenis 1.3.3，创建时指定 autoRaf:false、syncTouch:true、syncTouchLerp:0.05，并由渲染时钟调用 raf。桌面 lerp 未覆写，使用库默认 0.1。因此惯性主要来自逐帧追踪目标位置，而非 CSS smooth。

本站采用同一引擎的维护版本 Lenis 1.3.27，固定版本、本地打包，无运行时 CDN 请求。MIT 许可证见 dist/vendor/LENIS-LICENSE.txt；官方说明：https://github.com/darkroomengineering/lenis 。

## 当前代码中的问题

1. 原纵向页面只靠浏览器滚轮，CSS smooth 主要作用于锚点，不能为普通滚轮提供参考站的跟随与减速。
2. 原横向缓动时间常数 65ms，反应较急；逐帧读取经设备像素量化的 scrollLeft 再写回，微小位移容易停滞，尾端还有直接贴到目标的分支。
3. 轮播的 scroll 回调每次查询元素、读取 offsetLeft/scrollWidth 并无条件重写计数器和按钮状态，增加滚动期间的布局与样式工作。
4. 产品上的额外 drop-shadow 与 hover 变换、整屏暗角光影缺少明确合成边界，增加部分设备的绘制负担。

测试环境没有稳定复现持续低帧率，因此不将以上风险点表述为已经通过硬件性能追踪证明的唯一原因。修正针对可验证的顿挫机制和热路径开销，并用实际滚动采样验证。

## 修正

- 页面与横向轨道共用一个 requestAnimationFrame 时钟，Lenis 内部保存浮点位置；两轴均用 lerp:0.1。输入停止后自然减速，滚动停稳后时钟停止；后台页面暂停时钟。
- 取消旧的横向自写追赶循环，避免两套滚动方式混用。
- 禁用 Lenis 控制区域的 CSS smooth，避免重复缓动。
- 轮播卡片和控件引用缓存，尺寸只在 resize 时更新；仅当索引或禁用状态变化时更新 UI。
- 为封面、CD 和固定暗角建立合成边界，取消产品额外的滤镜投影；保留白灰配色、清晰文字、CD 滑出与屏幕外延伸的轨道。
- 鼠标拖动松手后根据末端速度投射至多 110px，再缓动停下；静止后松手不投射。触屏继续保留操作系统原生惯性，避免给已有惯性再叠一层。
- 支持减少动态效果偏好；弹窗打开时停止两轴引擎，关闭后恢复；键盘页滚动可中断惯性。锚点复用现有 scroll-padding，避免重复偏移。

| 纵向 | 8.4ms | 16.6ms | 0 | y +104.67px，x 0 |
| 横向 | 4.5ms | 12.5ms | 0 | x +107.33px，y 0 |
