# v1.4.0 更新与验证

- 隐藏各主要区块边角装饰文字，以及作品区底部提示、计数器与说明；功能按钮保留，计数器仍向辅助技术播报。
- 隐藏横向滚动条；桌面卡片宽度从 43% 调为 38%，平板 49%，手机 82%。
- 作品区滚轮优先横向滚动；到达边界后释放页面纵向滚动。保留拖动、方向按钮、键盘与原生触控滚动。
- 每张卡片配有相同产品图案的 CD：从背后向上滑出，旋转从 -12° 到 +8°；含金属反光、印刷图案及中心孔，支持键盘聚焦与减少动态效果偏好。
- 顶部导航和此前固定强度的外沿暗角保持原样。

验证：npm run check 通过。浏览器 1440×1000 实测滚轮使横向位置从 0 变为 75.33px，同时页面纵向位置保持 897.33px；达到横向边界后可继续纵向滚动。拖动、按钮和点击预览可用，CD 悬停旋转为 +8°。390px 与 320px 视口中卡片均保持同一行，无页面横向溢出。未在实体触屏设备上测试。
