# v1.6.0 连续横向滚动与清晰渲染

## 根因

v1.5 用 hidden 切换卡片，再通过 opacity 0→1 过渡，因此实际表现是换页闪现。现在取消分页和透明度动画，三张卡片始终位于同一条连续轨道。

此前全页 SVG feDisplacementMap 将正文、圆角和产品一起栅格化、重新采样；位移图使用 8 位通道，还叠加 ±0.42px 红蓝通道偏移。浏览器中导航清晰、被滤镜包裹的主体出现彩边和阶梯状边缘，与用户截图一致。当前取消整页非线性像素畸变、RGB 偏移和颗粒覆盖，保留独立的固定淡暗角；不再声称内容具有曲面位移。文字和圆角由浏览器原生渲染，未用模糊掩盖锯齿。

## 修改

- 轨道从区块内部扩展至整个屏幕宽度，卡片可连续延伸到屏幕外；不会在内容区域内部的窄容器处截断。
- 无换页、隐藏、透明度过渡和吸附；滚轮增量合并到同一动画帧队列，通过与帧间隔相关的缓动平滑推进。
- 横向触控板和触屏使用原生滚动；鼠标拖动直接跟随指针。按钮与方向键平滑滚动，Home/End 到两端。
- 支持减少动态效果偏好、缩放手势和滚动边界向纵向页面释放。处理设备像素量化，避免动画在末端剩余几像素处一直运行。
- 白灰配色、粉色强调、CD 滑出、卡片点击预览和不受影响的顶部导航保留。

## 验证

- npm run check 和 git diff --check 通过。
- 1440px 视口：整页 filter 为 none；三张卡片 hidden 数量 0、opacity 均为 1。轨道宽 1425px，与可用屏幕宽度一致，第三张自然延伸到屏幕外。
- 滚轮实测 scrollLeft 从 0 连续移动到 130.67px，页面 scrollY 保持 760.67px；没有隐藏卡片或透明度变化。
- 鼠标拖动 70px 对应 scrollLeft 70px，反向拖动回到起点；CD 悬停仍可见。
- 390px 视口滚轮位移 96.67px，三张卡片仍全部保留；End 后最后一张预览可正常打开与关闭。
- 320px 视口：页面 scrollWidth/clientWidth 同为 305px，End 停在真实滚动末端，下一张按钮正确禁用。未在实体触屏设备上测试。
