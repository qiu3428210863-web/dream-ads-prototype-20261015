# v1.8.0 CRT 曲面恢复

## 实现

- 页面内容先由 html2canvas 在首次加载、窗口尺寸变化及相关内容变化时缓存成高分辨率纹理。滚动期间不重新截图；WebGL 每帧按视口坐标执行径向 UV 位移，曲率系数为 0.16，并保留轻微边缘暗角。
- 顶部导航与原生模态框仍由 DOM 绘制，避免进入曲面纹理。滚动条继续使用 Lenis 共用时钟和轻惯性；横向轨道到端点后，向外滚动的 wheel/touch 输入放行给页面纵向滚动。
- 卡片悬停的 CD 使用独立纹理与 WebGL 动画；点击事件按曲面坐标映射回原始 DOM 交互区域。
- WebGL 不可用时保留原始 DOM 页面。曲面资源初始化失败会写入 `data-crt-status="fallback"` 并记录控制台原因，避免静默停在“capturing”。
- html2canvas 1.4.1 已本地固定，MIT 许可证随包保留；运行无需 CDN。

## 验证边界

`npm run check` 和 `git diff --check` 检查通过。此环境的浏览器安全策略拒绝读取本地预览页，因此本版没有新的可视化滚动帧率采样或浏览器截图；不要将 v1.7 的采样数据当作 v1.8 GPU 曲面实现的实测结果。旧 SVG 位移滤镜的低帧率试验数据单独保留在 `lens-scroll-y-v1.8.json`，不属于当前实现。
