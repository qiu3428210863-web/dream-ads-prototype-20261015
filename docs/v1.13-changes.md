# v1.13 — 卡片视图切换

- 右侧分享、下载按钮改为参考图灰色底、白色滑块的 Cards / Grid 分段选择器。
- Cards 保留原横向大卡片与居中停靠惯性；Grid 为桌面五列，常见桌面宽度下约原卡片一半宽度。1100px 以下三列，650px 以下两列，380px 以下单列。
- 用同一批 DOM 卡片做 FLIP 动画，从原位置和大小过渡至目标布局，缩至目标尺寸的 78%，弹至 104.5% 后回到目标尺寸。总时长 660ms。快速来回切换会取消旧动画，从当前画面继续。
- 卡片原有的 CD 滑出、图片悬停、视觉及点击预览保留。网格模式关闭横向滚轮、拖拽和停靠，正常纵向滚动；切回 Cards 后恢复。网格隐藏轮播箭头。
- 支持键盘按钮操作、aria-pressed 选中状态及减少动态效果偏好。
- 曲面镜头、暗角和文字渲染参数未变。

验证：`npm run check` 的 16 项测试通过，新增模式切换时取消停靠、纵向滚动释放、切回恢复横向滚动、快速切换取消动画以及减少动态效果的检查。资源检查覆盖新增 CSS 的相对路径。测试基于脚本 DOM 环境，不代表真实浏览器画面、布局或帧率验收。
