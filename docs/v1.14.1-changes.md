# v1.14.1 — 视图切换速度、间距与滚轮恢复

- 去掉切换过程中的 78% 缩小与 104.5% 回弹阶段，改为从当前画面到目标布局的连续缓动。
- 切换时长从 660ms 延长到 1160ms，增加 0.5 秒。保留减少动态效果偏好与无动画 API 时的直接切换。
- 网格桌面行距从 80px 调整到 48px，小屏从 64px 调整到 44px；列数、横向间距、卡片视觉和 CD 悬停效果保留。

滚轮问题的代码原因：原 `measureCarousel` 用卡片的 `getBoundingClientRect` 计算停靠点，用 `scrollWidth` 计算轨道范围。FLIP 动画会暂时改变前者及溢出范围；布局变化触发 ResizeObserver 时，测量可能读到过渡画面，动画结束又没有校准。此外，从网格切回时页面可能已经处于卡片停靠点下方，原先只检测“输入目标跨过停靠点”的逻辑不能重新接管。

修复后，卡片中心与轨道长度使用不受卡片变换影响的布局 offset 数据计算；所有当前切换动画结束后刷新 Lenis 尺寸和停靠点。取消的旧动画回调不能覆盖新视图。切回 Cards 后，在卡片区域继续向可移动方向滚轮操作，会先缓入停靠到中间，再将输入交给横向惯性；到边界后继续交接纵向滚动。

验证：先补充故障用例，确认旧逻辑在动画测量、切回后重新接管和动画完成校准上失败，再应用修复。`npm run check` 的 25 项检查通过，覆盖以上情况及原有滚动、视图和曲面逻辑。这些是脚本 DOM 检查，不是实机画面或帧率验收。正文曲面重采样链路未改动。
