# Showcase GPU 曲面渲染

Showcase 的卡片视觉由独立 WebGL2 画布绘制。画布以设备感知的高分辨率 Canvas 场景为输入，fragment shader 对每个输出像素直接计算曲面反向采样坐标。此链路不使用位移 PNG 或控制点网格，也不读取画布像素；只把绘制后的场景上传为 GPU 纹理。窗口尺寸、浏览器缩放和设备像素比变化时，按每帧合并更新画布尺寸。

现有卡片 DOM 保持原位，承担焦点、点击预览、文字语义和辅助技术内容；GPU 画布设置 `aria-hidden` 且 `pointer-events:none`。键盘焦点与悬停状态仍由 DOM 触发，GPU 视觉层同步呈现 CD、卡片文字及焦点边框。GL 初始化、素材上传或绘制失败时移除 GPU 视觉层并恢复原生 DOM 卡片。强制颜色模式和无 WebGL2 环境直接使用原生卡片。

边界：目前 GPU 曲面层仅应用于 Showcase 卡片。卡片文字由浏览器 Canvas 以高于输出尺寸的采样率重绘，然后由 GPU 做曲面采样；这是高分辨率栅格加线性纹理过滤，不是 MSDF 或原生字体轮廓着色。页面其他区块仍由原有 SVG DOM 曲面滤镜处理。要让所有区块都采用同等可控的 GPU 字形覆盖率，需要将其逐块迁移到可控 GPU 场景，并为中英文字符建立可授权、可扩展的字形图集。

渲染尺寸上限受设备 DPR、12MP 输出预算、12MP 源纹理预算及 WebGL 最大纹理边长共同约束。高 DPR 或超大窗口会降低内部超采样倍数，优先避免 GPU 分配失败和浏览器内存压力；因此不同设备上的清晰度仍会略有差别。还需要在 Windows、macOS、Linux、Android 与 iOS 的真实浏览器中做截图和帧率对照，脚本运行通过不能代替这些验证。
